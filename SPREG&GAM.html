#modelo_sarar2[]

Recordemos que el modelo SARAR sigue: \[\begin{cases} Y= \rho Wy + x^T\beta + u\\ U = \lambda Gu+\epsilon \end{cases}\]

y consideraremos \(\epsilon\sim N(0,\sigma^2I)\). Para resolverlo necesitamos las variables \(\lambda\), \(\rho\) y \(\beta\), de las cuales las dos primeras las hemos conseguido con el modelo SARAR de R y la \(\beta\) la vamos a obtener mediante:

Para calcular beta \[\beta = ((A_{\lambda}X)^{T}\Sigma^{-1}A_{\lambda}X)^{-1}(A_{\lambda}X)^{T}\Sigma^{-1}A_{\lambda}A_{\rho}y\] Al ser \(\Sigma = \sigma^2 I\) tendremos que en la expresion de la beta se nos va a simplificar obteniendo \[\beta = ((A_{\lambda}X)^{T}A_{\lambda}X)^{-1}(A_{\lambda}X)^{T}A_{\lambda}A_{\rho}y\]

# 5. Cálculo de beta_hat según fórmula completa
X_star <- A_lambda_train %*% X_train
Y_star <- A_lambda_train %*% (A_rho_train %*% Y_train)

# 6. Estimación de beta
XtX <- t(X_star) %*% X_star
XtY <- t(X_star) %*% Y_star
beta_hat <- solve(XtX, XtY)
