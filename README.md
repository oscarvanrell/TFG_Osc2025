# Modelos espacio-temporales para datos de panel: aplicación del SARAR al estudio de la natalidad en las provincias españolas
## TFG - Óscar Vanrell
## Grado de Matemáticas


Este repositorio contiene el código, datos y resultados asociados a mi Trabajo de Fin de Grado.

### Cómo ejecutar
1. Clonar el repositorio:
   git clone https://github.com/oscarvanrell/TFG_Osc2025.git
2. Abrir TFG_Osc2025.Rptoj en Rstudio
3. Ejecutar los scripts AnalisisExploratorio.qmd y TFGFinal.qmd, que muestran todos los códigos utilizados en el desarrollo del TFG, que usan el archivo DatosIniciales.RData que creé a partir de datos sacados del INE.
